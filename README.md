# WabiLink packages

Linux packages of the WabiLink server, as signed dnf and apt repositories, served at
**https://alexander-miglis.github.io/wabilink-packages/** - see that page to install.

```
curl -fsSL https://alexander-miglis.github.io/wabilink-packages/install.sh | sudo sh
```

This repository holds only the built packages, published here by the WabiLink build.
The `gh-pages` branch is the site, rewritten on each release.
